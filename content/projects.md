## React Starter Kit

An opinionated React project template with TypeScript, Vite, testing, and CI/CD pipelines pre-configured. Used by 500+ developers.

- **Stack**: React, TypeScript, Vite, Vitest, GitHub Actions
- **Links**: [GitHub](https://github.com/alexchen/react-starter)

## DevDash

A terminal-based developer dashboard that aggregates GitHub PRs, CI status, and on-call alerts into a single TUI.

- **Stack**: Go, Bubble Tea, GitHub API
- **Links**: [GitHub](https://github.com/alexchen/devdash), [Blog post](/blog/devdash)
